# Mitsui H&S Partners corporate website

黒を基調にした静的コーポレートサイトです。ビルド済みの HTML をそのまま Vercel / GitHub Pages 等で配信できます。追加パッケージのインストールは不要です。

## ローカル確認

Node.js で `npm run dev` を実行し、http://127.0.0.1:4173/ を開いてください。

## ページ

- `/` トップ・お問い合わせ（送信機能はデモ）
- `/business/` 事業内容（3事業の紹介）
- `/company/` 会社概要
- `/compliance/` コンプライアンス（方針案）
- `/news/` お知らせ一覧・本文の展開
- `/recruit/` 採用情報・職種紹介
- `/achievements/` 実績一覧・内容の展開
- `/blog/` 社員ブログ一覧・本文の展開
- `/message/` 社長メッセージ

## 編集

下層8ページの原稿・共通ヘッダー・フッターは `scripts/build-pages.mjs` で管理します。編集後 `npm run build` で HTML を再生成してください。トップ本文は `index.html` を直接編集できます（ヘッダーとフッターは再生成対象）。共通下層スタイルは `css/pages.css`、絞り込みなどの動作は `js/main.js` にあります。

`npm run check` で全9ページのリンク、画像、アンカー、見出し、JavaScript の構文を確認できます。

## 公開前の原稿確認

会社の正式な住所・代表者・設立・資本金・許可情報などは未提供のため「確認中」としています。コンプライアンスと社長メッセージは原稿案です。お知らせ、ブログ、実績、採用条件、画像はサンプルとして区別しています。実情報の確認・差し替えとお問い合わせの送信先設定が必要です。
